# Student Management System (SMS)

A complete, beginner-friendly console application built using **Core Java**, **OOP principles**, **DAO Design Pattern**, **JDBC**, and **MySQL**. Ready to run in **VS Code** and terminal environments.

---

## 📌 Project Overview

The **Student Management System** provides an interactive command-line interface (CLI) to manage student records with persistent MySQL database storage.

### Core Features
1. **Add a New Student**: Capture student Name, Department, Email, and Marks. The **Student ID** is automatically generated by the MySQL database.
2. **View All Students**: Display all enrolled students in a formatted ASCII table.
3. **Search Student by ID**: Look up and display the complete profile card of any student using their ID.
4. **Update Student Details**: Edit Name, Department, Email, or Marks with field-by-field prompts (press `Enter` to retain existing values).
5. **Delete a Student**: Remove a student record by ID with interactive `(y/N)` confirmation.
6. **Exit**: Gracefully terminate the application and release database resources.

## 🏛️ Architectural Pattern: Data Access Object (DAO)

The application cleanly separates responsibilities into distinct layers:

1. **Model Layer (`Student.java`)**:
   - Represents the Student entity.
   - Encapsulates private attributes: `id`, `name`, `department`, `email`, and `marks`.
   - Contains constructors, getters, setters, and formatted display utilities.

2. **Data Access Layer (`StudentDAO.java`)**:
   - Isolates all database operations from the UI.
   - Implements `addStudent()`, `getAllStudents()`, `getStudentById()`, `updateStudent()`, `deleteStudent()`, and `isEmailTaken()`.
   - Uses parameterized `PreparedStatement` and processes results with `ResultSet`.
   - Employs `try-with-resources` to ensure connections, statements, and result sets are always closed automatically.

3. **Presentation / Controller Layer (`Main.java`)**:
   - Coordinates the interactive console menu.
   - Handles user input reading, validation (marks 0-100, non-empty fields, valid emails).
   - Delegates persistence actions directly to `StudentDAO`.

4. **Infrastructure Layer (`DBConnection.java`)**:
   - Manages connection lifecycle and credentials from `db.properties`.
   - Automatically initializes the database and table on initial start.

## 🗄️ Database Setup (MySQL)

### Step 1: Verify MySQL Service
Ensure your MySQL server is running (Service name: `MySQL80` or `mysql`).

### Step 2: Create Database & Tables
Execute the provided `schema.sql` script using MySQL Workbench or the MySQL Command Line Client:

```sql
SOURCE schema.sql;
```

Or execute directly:
```sql
CREATE DATABASE IF NOT EXISTS student_db;
USE student_db;

CREATE TABLE IF NOT EXISTS students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    department VARCHAR(100) NOT NULL,
    email VARCHAR(150) NOT NULL UNIQUE,
    marks DECIMAL(5, 2) NOT NULL
);
```

> **Note:** `DBConnection.java` also automatically executes table creation on launch if the MySQL server is reachable.

## 🔒 Secure Configuration (Credentials Management)

Never hardcode database passwords in source code or commit them to GitHub. This system supports a secure, multi-tier configuration hierarchy:

### Approach 1: Environment Variables (Recommended for Security)
Set your MySQL credentials as environment variables in your terminal session or system settings:

**PowerShell (Windows):**
```powershell
$env:DB_USER = "root"
$env:DB_PASSWORD = "YourSecurePassword"
$env:DB_URL = "jdbc:mysql://localhost:3306/student_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC"
```

**Command Prompt (Windows CMD):**
```cmd
set DB_USER=root
set DB_PASSWORD=YourSecurePassword
set DB_URL=jdbc:mysql://localhost:3306/student_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
```

**In VS Code (`.vscode/launch.json`):**
Add an `env` block to `.vscode/launch.json`:
```json
"env": {
    "DB_USER": "root",
    "DB_PASSWORD": "YourSecurePassword"
}
```

---

### Approach 2: Local `db.properties` File (Git-Ignored)
Alternatively, edit [`db.properties`](db.properties) in the root directory. This file is excluded in [`.gitignore`](.gitignore) so your passwords will never be committed to Git:

```properties
db.url=jdbc:mysql://localhost:3306/student_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
db.user=root
db.password=YourSecurePassword
```

## 🚀 How to Run

### Method 1: In VS Code (Recommended)
1. Open this project folder in **VS Code**.
2. Open [`src/Main.java`](src/Main.java).
3. Press **F5** or click the **Run** button at the top right of the editor.

### Method 2: From Terminal (PowerShell / Command Prompt)

1. Open a terminal in the project root directory.
2. **Compile** all Java source files into the `bin` directory:
   ```powershell
   javac -cp ".;lib\mysql-connector-j-8.4.0.jar" -d bin src\DBConnection.java src\Student.java src\StudentDAO.java src\Main.java
   ```
3. **Execute** the application:
   ```powershell
   java -cp "bin;lib\mysql-connector-j-8.4.0.jar" Main
   ```

*(On macOS / Linux, replace `;` with `:` in classpath: `-cp "bin:lib/mysql-connector-j-8.4.0.jar"`)*

## ❓ Troubleshooting

| Issue | Solution |
| :--- | :--- |
| **`Access denied for user 'root'@'localhost'`** | Enter your correct MySQL root password in `db.properties`. |
| **`Communications link failure`** | Ensure the MySQL service (`MySQL80`) is running in Windows Services (`services.msc`). |
| **`ClassNotFoundException: com.mysql.cj.jdbc.Driver`** | Verify that `lib/mysql-connector-j-8.4.0.jar` is included in the `-cp` flag when running. |
| **`Unknown database 'student_db'`** | Run `schema.sql` or create it manually: `CREATE DATABASE student_db;`. |
